Rule-based classification

Question 1 What happens when a rule-based classifier finds a new pattern in the training data?

  1. It adjusts its thresholds by itself
  2. Nothing changes ✔ Correct
  3. It updates its weights by gradient descent

Explanation A rule-based model has no training step. Its decisions stay the same until a person changes the rules.

2 points · 2 points for choosing the correct answer and giving the reason in one sentence; 1 point for choosing the correct answer only; 1 point for a wrong answer that still states the key reason from the explanation (at the level of the words in parentheses).

Question 2 If the rule is "x₁ > 0.5 and x₂ > 0.4 → A, otherwise B", what is the answer for x = (0.6, 0.2)?

  1. A
  2. B ✔ Correct

Explanation x₁ > 0.5 is true but x₂ > 0.4 is false, so the whole "and" condition is false and the default B applies.

K-nearest neighbors

Question 3 What tends to happen to the boundary when k = 1?

  1. It becomes smooth
  2. It gets jagged, swayed by every individual point ✔ Correct
  3. It becomes a straight line

Explanation Because it looks only at the single nearest point, one noisy point can completely change the decisions around it. This is a textbook case of overfitting.

Question 4 What problem arises if you feed height (cm) and body weight (kg) as they are into KNN?

  1. The feature with larger units dominates the distance ✔ Correct
  2. Training takes longer
  3. No problem

Explanation Distance is sensitive to the size of the numbers. You need scaling such as standardization to bring the features to comparable ranges.

Decision tree

Question 5 Why are a decision tree's decision boundaries always parallel to the axes?

  1. Because its questions take the form "one feature ≤ value" ✔ Correct
  2. Because the data was originally shaped that way
  3. Because Gini impurity only produces straight lines

Explanation It splits on only one feature at a time, so the boundary lines have the form x₁ = t or x₂ = t, i.e. lines parallel to the axes.

Question 6 What is the Gini impurity of a cell with 6 A's and 4 B's?

  1. 0.24
  2. 0.48 ✔ Correct
  3. 0.52

Explanation 1 − (0.6² + 0.4²) = 1 − (0.36 + 0.16) = 0.48.

Perceptron

Question 7 What happens to the weights when a perceptron predicts correctly?

  1. They get a little larger
  2. They get a little smaller
  3. They don't change ✔ Correct

Explanation When it's correct, y − ŷ = 0, so w ← w + 0. It learns only from the examples it gets wrong.

2 points · 2 points for choosing the correct answer and giving the reason in one sentence; 1 point for choosing the correct answer only; 1 point for a wrong answer that still states the key reason from the explanation (at the level of the words in parentheses).

Question 8 Which problem can a single perceptron never solve?

  1. Two groups separable by a straight line
  2. Problems that can't be separated by a straight line, like XOR ✔ Correct
  3. A problem with 2 classes

Explanation Its decision boundary is just one straight line, so it can't separate data mixed diagonally like XOR. You need to stack layers to solve it.

Logistic regression

Question 9 What is σ(z) when z = 0?

  1. 0
  2. 0.5 ✔ Correct
  3. 1

Explanation Since e⁰ = 1, it is 1/(1+1) = 0.5. That is why the place where z = 0 becomes the decision boundary.

2 points · 2 points for choosing the correct answer and giving the reason in one sentence; 1 point for choosing the correct answer only; 1 point for a wrong answer that still states the key reason from the explanation (at the level of the words in parentheses).

Question 10 What shape is the decision boundary of logistic regression?

  1. A straight line ✔ Correct
  2. Circle
  3. Free-form curve

Explanation The probability is 0.5 where w·x + b = 0, which is a straight line (a hyperplane in higher dimensions). It merely adds a probability output; the boundary has the same shape as the perceptron's.

Linear support vector machine

Question 11 Which points determine an SVM's boundary?

  1. All training points
  2. The support vectors that touch the edge of the road or fall inside it ✔ Correct
  3. The farthest points

Explanation Only the points that touch or violate the margin affect the objective function. Points far away can be removed and the boundary stays the same.

Question 12 What happens if you make C larger?

  2. It tries to reduce violations even if the road gets narrower ✔ Correct
  3. No change

Explanation C is the weight of the penalty. When it is large, the model hates mistakes and narrows the road; when it is small, it allows violations in exchange for a wider road. You can see this in the C adjustment figure below.

Kernel support vector classifier

Question 13 What is the key idea of the kernel trick?

  1. Compute and store φ(x) directly
  2. Compute only the similarity K between two points, without computing φ ✔ Correct
  3. Reduce the dimension of the data

Explanation Computing just K(xᵢ, x) instead of the high-dimensional coordinates gives the same result as the dot product in the high-dimensional space.

Deep learning: multilayer perceptron

Question 15 What happens if you remove the activation function g from all hidden layers?

  1. It becomes more expressive
  2. No matter how many layers you stack, it becomes equivalent to a single linear expression (a straight-line boundary) ✔ Correct
  3. Only training gets faster; the results are the same

Explanation W₃(W₂(W₁x)) = (W₃W₂W₁)x, so everything collapses into a single linear transformation. You need a bending function to get curved boundaries.

Question 16 The output layer (softmax) of deep learning has the same formula as which model?

  1. KNN
  2. Logistic (softmax) regression ✔ Correct
  3. Decision tree

Explanation The last layer is the same formula as softmax regression; the only difference is that its input is h(x).

Basic assignment · Changing KNN's k

In the code from Part 1, Section 10, "Comparing models on the 7 fish species", change KNN's k to 1, 5, and 15 and compare the 5-fold cross-validation accuracy.

for k in [1, 5, 15]:
    knn = make_pipeline(StandardScaler(), KNeighborsClassifier(n_neighbors=k))
    s = cross_val_score(knn, X, y, cv=cv, groups=groups)   # keep each original group on one side only
    print(f"k={k:<3} {s.mean():.3f} ± {s.std():.3f}")

Sample results (scikit-learn 1.8, CPU): k = 1 → 0.920 ± 0.019, k = 5 → 0.900 ± 0.033, k = 15 → 0.871 ± 0.035.

Sample interpretation On this data, the smaller k was, the higher the score. That's because the boundaries between species are tight, so the single nearest neighbor is the most reliable. However, the difference between k = 1 and k = 5 (0.02) is about the size of the standard deviation, so it's hard to say k = 1 is "clearly better."

Grading points ① Did they keep groups=groups? ② Did they report the mean together with the standard deviation? ③ Did they avoid drawing firm conclusions when the difference was within the standard deviation?

Correcting errors in data splitting

Question 1 In data where the minority class is 5%, what is the accuracy of a model that answers "all majority class"?

  1. About 50%
  2. 0%
  3. About 95% ✔ Correct

Explanation It gets 95 out of 100 right, so the accuracy is 95%. But it finds none of the minority class, so recall is 0. With imbalanced data, you must not look at accuracy alone.

2 points · 2 points for choosing the correct answer and giving the reason in one sentence; 1 point for choosing the correct answer only; 1 point for a wrong answer that still states the key reason from the explanation (at the level of the words in parentheses).

Question 2 What happens if you apply StandardScaler to the whole dataset first and then run train_test_split?

  1. Leakage occurs: the mean and variance of the test data get mixed into training ✔ Correct
  2. Nothing goes wrong
  3. Training becomes slower

Explanation This is because the scaler also looked at the test data when computing the mean. Put the scaler inside a Pipeline so that it is fit only on the training folds of each cross-validation split.

Question 5 What should you try first for a model with training accuracy 1.00 and test accuracy 0.86?

  2. Add even more features
  3. Increase the learning rate

Explanation A large gap between training and test is a sign of overfitting. Regularization (increase λ = decrease C) or reducing the number of features comes first.

Question 6 Why does L1 regularization, unlike L2, have a "feature selection" effect?

  1. Because it computes faster
  2. Because it enlarges all coefficients
  3. Because it makes some coefficients exactly 0 ✔ Correct

Explanation Because of the diamond shape of the L1 penalty, the minimum tends to land on an axis (where one coefficient is 0). A feature whose coefficient becomes 0 is effectively not used.

Question 7 What is random forest most closely related to?

Explanation It is bagging, which grows many trees on bootstrap samples, with each split looking at only some of the features so that the trees resemble each other less.

Basic assignment · Splitting by row vs by fish

Run the "Looking at it by fish" code from Chapter 1, tabulate the by-row and by-fish cross-validation scores of the three models, and write which model shows the largest difference and why.

Sample results KNN (k = 1) 0.959 → 0.920, logistic regression 0.909 → 0.899, decision tree 0.884 → 0.872 (using only the original 158 fish: 0.810, 0.804, 0.735).

Sample interpretation KNN (k = 1) shows the largest difference. The lower scores with only the originals are not due to leakage but to having less training data.

Challenge assignment · L1 regularization strength and feature selection

In the Chapter 3 code, change C of the L1 regularization to 10, 1 and 0.1, compare the number of remaining features and the cross-validation scores, and interpret the signs of the length2 and length3 coefficients.

Sample results C = 10 → 6/9 features remain, 1.000 · C = 1 → 6/9, 0.997 · C = 0.1 → 3/9, 0.877. When C is 10 and 1, length2 and length3 get large coefficients of similar size but opposite sign (about −73 and +73, −32 and +33).
