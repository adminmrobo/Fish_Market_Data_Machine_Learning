分類モデルはすべて一つの関数である

人が書いたif-thenルールから、数千から数千億個の重みを持つディープラーニングまで、分類モデルはすべて入力xを受け取ってクラスŷを返す関数f(x)です。8つのモデルの違いは3つだけです。関数の形、その中の数字を決める方法、そしてその結果として生まれる決定境界の形です。

問題：この魚はどの種だろう？Fish species classification

分類モデルとは何かを説明する前に、解く問題から決めましょう。

1問題の定義

魚市場では魚を獲るたびに重さ、長さ、高さ、幅を測ります。この数字だけを見てどの種なのかを当てたいのです。人は「丸々としていればブリーム、細くて小さければキュウリウオ」のように勘で見分けますが、私たちはその判断を数字によるルール、つまり関数にしようとしています。

種 = f(体長, 体高, 体幅, …)

入力は測った数値で、出力は種の名前です。これが分類問題です。使うデータは7種1,554匹の測定値です（公開データを拡張、4を参照）。このページでは7種のうち2組を選んで使います。ブリーム vs キュウリウオは誰が見ても違う簡単なペア、パーチ vs ローチは大きさも形も似ている難しいペアです。

データの出典と拡張の方法
元データはKaggleで公開されているFish Marketデータセット（https://www.kaggle.com/datasets/vipullrathod/fish-market）で、フィンランドのある湖で獲れた7種159匹の測定データです。この資料では、元データを正規分布を考慮して約10倍に拡張しました。データから確認した拡張の方法は次のとおりです。
  • 大きさ：元の魚ごとに、大きさの倍率を平均1、標準偏差約0.12の正規分布に近い形で抽出し、長さ・高さ・幅にまとめて掛けました。そのため複製は、元の魚より少し大きいか小さい「似た魚」になります。
  • 重さ：体積に合わせて大きさの倍率の約3乗で変化させ（データから確認した傾きは3.1）、そこに約5%のノイズを加えました。
  • 形：体型比には約3%、尾の比率には0.5%程度の小さなノイズだけを加えたので、種固有の形は保たれます。
  • 整理：重さが誤って0と記録された元データ1行と、完全に重複する35行を除いて1,554匹になりました。

ブリーム（Bream）は、韓国語の原文では国内の入門書の慣例に従った訳語が使われていますが、実際にはヨーロッパの淡水魚ブリームです。拡張された魚は元の魚をもとに作られているため、同じ元の魚から生まれた魚同士は互いに似ています。すぐ下の5で、この点がなぜ重要なのかを示します。

系統A人が書いたif-then

1モデル

専門家が知っている判断基準をif-then文に書き写したモデルです。データから学習せず、ルールのリストそのものが関数です。

4解釈

左のフローチャートの2つの質問が、右の平面を2本の点線で切ります。2つの条件を両方満たす右上の長方形だけがAになり、残りはすべてBです。

ポイントはデータを見ずに境界を決めたという点です。そのため、左上の緑の点のように、ルールを書いた人が予想しなかったデータはそのまま間違えます。この誤りを減らすには、人がルールをもう一つ追加しなければなりません。

k近傍法K-Nearest Neighbors, KNN

系統A距離で投票

1モデル

新しいデータが入ってくると、保存しておいたデータの中から最も近いk個を見つけ、多数決でクラスを決めます。「似ているものは近くにある」という仮定一つで動きます。

パラメータの決定なし（データを保存）
決定境界ギザギザの曲線
ハイパーパラメータk、距離尺度

かんたんに言うと引っ越してきたばかりの町でどの食堂が良いか分からないとき、自分の家から一番近いご近所さん5人に聞いて多数決で決めるようなものです。近くに住んでいる人ほど好みが似ていると信じているわけです。

紫のひし形が新しい点です。すべての点との距離を測ったあと、最も近い5個を選ぶとAが3票、Bが2票なのでAに分類します。

KNNには学習段階で計算する数字が一つもありません。データを保存しておくだけで、質問が来たときに初めて計算します（怠惰学習）。つまり「関数の式」が別にあるわけではなく、保存されたデータ全体が関数の役割を果たします。

kが小さいと境界が1〜2個の点に振り回されてギザギザになり（過学習）、kが大きいと境界がぼやけます（未学習）。

ペア

最も近い近傍がすべて同じ種なので、kをいくつにしても100%です。群れが遠く離れているときは、KNNが最も簡単に勝ちます。

簡単に言えば工場の組み立てラインのようなものです。最初の工程で原材料を加工し、次の工程で加工した部品を組み立て、最後に検査員が合格・不合格を判定します。不良品が出たら、検査員から最初の工程まで逆向きにさかのぼりながら、各工程のやり方（重み）を少しずつ直します。この「逆向きに直す」作業が誤差逆伝播法です。

f3(f2(f1(x))),   fl(h) = g(Wlh + bl)
  • 同じ形の層の関数を何度もつなげる
  • 層の形だけ決めて、W, bはすべて学習
  • 係数は数千個（小さなモデル）から数千億個（大規模言語モデル）まで
  • 係数一つひとつの意味を人が読み取るのは難しい

ディープラーニングは新しい数学ではありません。「掛けて、足して、折る」という計算を層単位で膨大な回数繰り返した合成関数です。

1つの層 = 複数のパーセプトロンを一度に = 行列積。3個のニューロンがそれぞれw·x + bを計算するのを行列にまとめると、Wx + bという1回の計算になります。ディープラーニングにGPUが必要なのは、この行列積を同時に何千個も処理するからです。

なぜ折る（g）必要があるのか？gがなければW₃(W₂(W₁x)) = (W₃W₂W₁)x となり、層を100個積み重ねても結局1つの一次式、つまり1本の直線の境界にまとまってしまいます。ReLU(z) = max(0, z)のように0で一度折り曲げるだけで、層ごとに境界を曲げられるようになります。

7順伝播を追う: 入力が確率になるまで
正の重み負の重み線が太いほど|w|が大きい
  1. 隠れ層: ニューロンごとにパーセプトロンの計算（掛け算、足し算）をした後、ReLUで負の値を0に折る
  2. 同じ計算を行列で一度に: h = ReLU(W₁x + b₁)
  3. 出力層のスコア: 隠れ値hを入力として、クラスごとにもう一度掛けて足す
  4. ソフトマックス: esを求めて全体の和で割ると、合計1の確率になる
  5. 予測: 確率が最も大きいクラス
8誤差逆伝播を追う: 間違えた分を逆向きに分けて直す

学習は4つのステップの繰り返しです。① 順伝播で確率pを求め、② 正解と比べて損失Lを測り、③ 各重みが損失にどれだけ責任があるか（勾配）を出力層から逆向きに計算し（誤差逆伝播法、連鎖律）、④ 勾配の反対方向に重みを少し動かします。正解を選んで「学習1回」を押してみてください。

  1. 損失: 正解クラスに与えた確率の−log
  2. 出力層の誤差 δ = p − y（予測確率 − 正解のワンホット）
  1. 重みの勾配: ∂L/∂W₂[k][j] = δₖ × hⱼ（誤差 × その線から入ってきた値）
  2. 更新結果
    まだ学習していません。

δが負である正解クラスは重みが大きくなってスコアが上がり、δが正である不正解クラスはスコアが下がります。隠れ層の重みW₁も同じ方法で、δをさらに1層逆向きに伝えて一緒に直します（この実習でも実際に計算して反映しています）。

from sklearn.preprocessing import StandardScaler
from sklearn.neighbors import KNeighborsClassifier
from sklearn.tree import DecisionTreeClassifier
from sklearn.linear_model import Perceptron, LogisticRegression

損失

たとえダーツが的の中心から外れた距離。遠いほど点数が悪くなります。

内積

たとえ買い物の会計。品目ごとに数量 × 価格を掛けてすべて足すと合計金額になります。

意味2つのベクトルの同じ位置どうしを掛けて足した値。w·xがまさに内積です。

超平面

たとえ部屋を2つに分ける仕切り。2次元では線、3次元では板で、さらに高い次元でも同じ役割を果たします。

意味n次元空間を2つに分ける(n−1)次元の平らな境界。

マージン

たとえ車線の間の安全距離。広いほど少しふらついても隣の車にぶつかりません。

意味決定境界から最も近い点までの余裕。SVMはこの幅を最大化します。

サポートベクター

たとえテントを固定する杭。杭を動かすとテントの形が変わりますが、中の荷物を動かしても形はそのままです。

意味マージンの縁に触れているか、内側に入り込んだ学習点。これらの点だけが境界を決めます。

カーネル

たとえ2人がどれだけ似ているかを測る"似ている度メーター"。座標をいちいち移さずに、似ている度合いだけを測ります。

意味2つの点を高次元に移した後の内積を直接計算する関数K(xᵢ, x)。

次元の呪い

たとえ階と部屋が果てしなく増えるホテルで友達を探すこと。部屋が増えるほど、誰もが互いに遠く離れていきます。

意味特徴（次元）が多くなるとデータがまばらになり、距離が意味を失う現象。

スケーリング

たとえ身長(cm)と体重(kg)を比べる前に単位をそろえること。そろえないと、数字が大きいほうが勝ってしまいます。

意味特徴どうしの範囲を同じくらいにそろえる前処理。標準化は"平均0、標準偏差1"に変換します。

ニューラルネットワーク

活性化関数

たとえ水道の蛇口。入ってきた信号をどれだけ流すかを決めます。

意味ニューロンの合計zにかぶせる関数。これがあってこそ曲線の境界を作れます。

ReLU

たとえ一方向にしか開かない逆止弁。負の値は止め(0)、正の値はそのまま通します。

意味ReLU(z) = max(0, z)。

tanh

たとえ両端が止まったシーソー。いくら押しても−1から+1の間でしか動きません。

意味値を−1〜1の間に押し込めるS字型の関数。

順伝播

たとえベルトコンベア。原料が最初の工程から最後の工程まで一方向に流れていきます。

意味入力から出力の方向へ、層を順番に計算していく過程。

行列積

たとえクラス全員の答案を一度に採点する一括処理。

意味複数のパーセプトロンのw·x + bをまとめて計算する方法。

普遍近似定理

たとえレゴブロック。ブロックが十分にあれば、どんな形でもまねできます。

意味隠れ層のニューロンが十分にあれば、ニューラルネットワークはどんな連続関数でも望むだけ近くまねできるという定理。

評価と汎化

過学習

たとえ過去問の答えを丸暗記した生徒。過去問は満点でも、初めて見る問題は解けません。

意味学習データにはよく合うが、新しいデータでは性能が落ちる状態。

未学習

たとえ教科書をざっと流し読みしただけの生徒。過去問も新しい問題も解けません。

意味モデルが単純すぎて、学習データさえうまく当てられない状態。

ハイパーパラメータ

たとえ料理人があらかじめ決める火加減と調理時間。材料(データ)を見て自然に決まるものではありません。

意味学習の前に人が決める設定値。k、木の深さ、C、γ、学習率など。

交差検証

たとえ問題用紙を替えながら模擬試験を何度も受けて平均をとること。一度だけ運よく取れた点数にだまされません。

意味データをk個に分け、順番に1つをテスト用に使って点数を平均する評価方法。

怠惰学習

たとえ試験前には勉強せず、問題を受け取ってから参考書をめくる学生。

意味学習段階では計算せず、予測するときに計算する方式。KNNが代表例です。
